# sunmall: grilled potato chips landing page
a responsive landing page for **sunmall**, a fictional snack brand. Built with plain HTML, CSS and a little javascript, based on a UI reference design.

## Features
-responsive navbar with searchbox, cart badge and hamburger menu on mobile
-Hero section with headline, "add to cart" button and quantity selector
-Center Product  image with decorative circle behind it
-product benefit icons (100% natural, oven grilled, tasty & crunchy)
-Feature highlights (Extra chili, beef Flavour, smokey sauce) with icons
-"Our top flavours" with product cards, rating, prices and order buttons
-packet images that overflow the cards using CSS absolute positioning

##Built with
- HTML5
- CSS3
- javascript(mobile menu toggle)
- [Google Fonts](https://fonts.google.com/): Roboto Condensed, Lilita One
- [Font Awesome](https://fontawesome.com/) 6.5.2 for icon

##🚀 Getting Started

1. Clone the repository
   ```bash
   git clone(https://github.com/Vishal-kumar-tech/too-yumm-web-page.git)
   ```
2. Open the folder
   ```bash
   cd sunmall
   ```
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension.

No build tools or dependencies are needed. An internet connection is required to load the fonts and icons from their CDNs.

## 📱 Responsiveness

The navbar collapses into a hamburger menu below `900px`. Other sections are still being adapted for smaller screens.
